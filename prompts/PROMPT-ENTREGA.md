# Prompt para entregas futuras

Leia as instruções locais e abra docs/00-governanca/01-POLITICA-IA.md e POLITICA-DOCUMENTACAO.md, Manual Vivo, ticket e capítulos afetados. Execute apenas o incremento autorizado com critério/baseline/revisão reais.

Identifique impacto e mantenha código + documentação atual + histórico na mesma entrega. Atualize módulo/feature/contrato/arquitetura/runbook/desenvolvimento conforme matriz; ADR somente para decisão estrutural; lesson somente com conceito aplicado e código/revisão/evidência reais. Não recrie toda documentação nem copie contratos entre capítulos.

Crie docs/09-entregas/<ano>/AAAA-MM-DD-TICKET-titulo.md pelo template: objetivo/problema/solução/funcionamento/arquivos/diff/dados/API/testes/resultados/segurança/riscos/limitações/rollback/docs/uso/custos/pendências/aceite. Atualize índices/changelog/backlog/matriz afetados. Não abrir novos relatos em documentacoes/.

Verifique links/estrutura e veracidade frente ao código/checks da revisão final. Marque NOT_RUN/unknown quando faltam evidências; nenhuma declaração do modelo ou exit code prova conclusão. Até duas correções; depois checkpoint com patch/untracked/hash e quiescência. DONE só após aceite humano da revisão exata. Finalize com mudança, funcionamento, checks, limites, rollback, docs e estado do aceite.
