# Plano de isolamento local

Artefatos operativos em docs/09-entregas/AAAA/evidencias/ID/: plano, prompt por frente e estado. Esses registros identificados não são novos capítulos do manual. Registrar root/worktree/branch/base SHA, ticket, paths autorizados, ownership, contratos entre frentes, checks, evidências e parada/handoff.

Descobrir topologia com Git de leitura. Base indicada pelo usuário; confirmar developer quando integração local. Nome/path de worktree escolhido a partir do ambiente real, sem Windows nem limite fixo backend/frontend. Não gerar comandos com placeholders não resolvidos. Um writer por workspace; trabalhos dependentes seguem sequência.

Prompts abrem explicitamente AGENTS, políticas e skills canônicas. Regras adicionais em fixtures continuam locais. Não presumir descoberta automática em sessão nova.

Antes de merge autorizado: revisão exata, gates exigidos, origem/destino e estado local. Antes de remover: commits integrados ou backup verificável, patch/untracked conferidos, writer comprovadamente parado. Falha de permissão ou trabalho desconhecido impede remoção, sem force/reset. Plano sozinho não autoriza executar Git de escrita.
