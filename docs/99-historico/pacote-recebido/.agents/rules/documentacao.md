# Ponte para documentação

Abra e aplique a [política comum](../../docs/00-governanca/POLITICA-IA.md) e a [política documental](../../docs/00-governanca/POLITICA-DOCUMENTACAO.md). Estado atual e registro de entrega são obrigatórios; lessons condicionais à aplicação real. Não criar política paralela nesta pasta.

Verifique carregamento no agente/versão instalada; este path não garante descoberta automática. Se ignorado, incluir políticas e guia explicitamente no prompt. Esta ponte não define permissões de runtime.
