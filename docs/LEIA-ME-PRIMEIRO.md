# Como ler este sistema

| Objetivo | Ordem sugerida |
|---|---|
| Primeira leitura, 10–15 min | Manual Vivo → visão geral → mapa do sistema |
| Entender arquitetura | contexto → containers → componentes → fluxos → dados → ADRs |
| Alterar um módulo | política → README do módulo → contrato/feature afetados → testes → template de entrega |
| Operar | infraestrutura → execução/recuperação → deploy → backup/restore → troubleshooting |
| Retomar após pausa | checkpoint → confirmação de quiescência → revisão/patch/untracked → checks afetados |
| Auditar migração | auditoria → inventário → mapa → manifesto → originais |

As durações são sugestões de leitura. PLANEJADO descreve intenção, IMPLEMENTADO exige caminho/revisão e evidência, NÃO VERIFICADO indica ausência de validação. Estado da decisão (proposta/aceita/superada) é separado do estado da implementação.

Não é preciso ler todo o histórico para entender o desenho atual. Abra o histórico para verificar origem ou mudanças de direção.
