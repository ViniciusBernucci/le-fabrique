# FAC-017 — Confirmar a assinatura Codex

Conectar assinatura Codex reserva uma aba de espera e segue para a URL oficial quando o worker fornece o desafio; link/código também aparecem no modal. O operador autoriza no site oficial. Abrir uma aba ou ver RUNNING não é sucesso; aguarde COMPLETED/AVAILABLE, depois catálogo verificado. Expiração/falha permite nova tentativa.

O diagnóstico real corrigido comprovou publicação de desafio, sem autorização nem inferência. A sessão anterior do usuário não concluiu login.
